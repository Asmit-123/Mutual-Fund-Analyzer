# Five-minute demo script

Target duration: 4 minutes 30 seconds.

## 0:00–0:25 — Introduce the app
Open the production URL. Explain that the application turns 2–10 Indian mutual funds into a NAV-backed comparison and downloadable AI-written PDF.

## 0:25–1:20 — Search and select funds
Use the live AMFI scheme search. Select two or three schemes. Show the scheme code, latest NAV and date in the suggestion results. Explain that the list comes from the current scheme master, not a hard-coded catalogue.

## 1:20–1:50 — Paste-list and period controls
Show the paste-list field and the 1Y / 3Y / 5Y / 10Y period options. Explain that the interface accepts between two and ten distinct schemes.

## 1:50–2:45 — Generate the report
Click Generate ranked report. Explain that the backend retrieves each NAV history, calculates returns and risk metrics, validates the data, and rejects an incomplete comparison rather than silently ranking only the funds that succeeded.

## 2:45–3:45 — Review ranking and methodology
Show the executive summary, ranking explanations, comparison table and individual fund detail sections. Explain the transparent 40% CAGR / 30% volatility / 30% drawdown weighting. Mention that the score is relative to the selected set and is not a universal fund rating.

## 3:45–4:20 — Download PDF
Click Download PDF. Open the downloaded PDF and quickly show the ranking, comparison table, methodology and disclaimer.

## 4:20–4:30 — Close
Mention the AMFI primary source, MFapi.in fallback, automated backend tests and the fact that benchmark TRI metrics are not claimed until a validated benchmark series is integrated.
